📧 Gmail 서명 등록 방법

  1. 아래 점선 박스 안의 서명을 마우스로 드래그 → 전부 선택 후 복사 (Ctrl+C / ⌘+C)
  2. Gmail ⚙️ → 모든 설정 보기 → 기본설정 탭 → 서명 섹션
  3. + 새로 만들기 → 서명 이름 지정 (예: "Yi Youme / COO")
  4. 편집창에 붙여넣기 (Ctrl+V / ⌘+V)
  5. 아래 서명 기본값에서 신규 메일용 / 답장 · 전달용에 지정
